# Modul 3: CSS (Cascading Style Sheets)

Modul ini bertujuan untuk memperkenalkan CSS sebagai bahasa *stylesheet* yang digunakan untuk mengatur tampilan, desain, dan layout sebuah dokumen HTML.

## Materi Pembahasan
Pada modul ini, kita akan mempelajari:
1.  **Pengenalan dan Sintaks CSS:** Memahami cara kerja CSS yang memisahkan isi dokumen dengan presentasi (tampilan). Mempelajari penulisan *Property* dan *Value*.
2.  **Macam-macam Selector:** Cara menunjuk elemen HTML yang akan diubah tampilannya, meliputi *Tag selector*, *ID selector*, *Class selector*, dan *Group selector*.
3.  **Penempatan CSS:** Memahami 4 cara menyisipkan CSS ke dalam HTML:
    *   *Inline Style* (di dalam tag HTML)
    *   *Internal Style* (di dalam tag `<head>`)
    *   *Import Style* (mengimpor file CSS lain)
    *   *External Style* (menghubungkan file `.css` terpisah menggunakan tag `<link>`)
4.  **Properti CSS Dasar:** Mengatur warna (`color`, `background-color`), teks, *border*, *margin*, *padding*, *box-shadow*, dan *background image*.

## File Praktikum
*   `percobaan1.html` - Praktikum mengatur border dan warna background menggunakan *Inline Style*.
*   `percobaan2.html` - Praktikum mengatur teks (warna, ukuran, posisi) menggunakan *Internal Style*.
*   `percobaan3.html` - Praktikum membuat custom button (padding, margin, shadow) dengan pseudo-class `:hover` dan `:active`.
*   `percobaan4/` (Folder) - Berisi `percobaan4.html` dan `gambar.jpg` untuk mempraktikkan *background image*.
*   `percobaan5/` (Folder) - Berisi `percobaan5.html` dan `percobaan5.css` untuk mempraktikkan *External Style* pada sebuah Form.
*   `latihan.html` - Latihan mengatur layout sederhana menggunakan CSS.
