# Modul 1: HTML Dasar

Modul ini bertujuan untuk memberikan pemahaman mengenai dasar-dasar bahasa HTML (*HyperText Markup Language*) sebagai bahasa standar untuk membuat halaman web statis.

## Materi Pembahasan
Pada modul ini, kita mempelajari konsep-konsep dasar HTML, meliputi:
1.  **Struktur Dasar HTML:** Penggunaan `<!DOCTYPE html>`, `<html>`, `<head>`, `<title>`, dan `<body>`.
2.  **Tag, Elemen, dan Atribut:** Aturan penulisan tag pembuka dan penutup, serta penggunaan atribut untuk memberikan informasi tambahan.
3.  **Heading dan Format Teks:** Penggunaan tag `<h1>` hingga `<h6>`, serta tag pemformatan teks seperti `<b>`, `<i>`, `<u>`, dan lainnya.
4.  **Gambar:** Menyisipkan gambar menggunakan tag `<img>` beserta atribut `src`, `alt`, `width`, dan `height`.
5.  **List:** Membuat daftar berurutan (*Ordered List* - `<ol>`), daftar tidak berurutan (*Unordered List* - `<ul>`), dan daftar deskripsi (*Description List* - `<dl>`).

## File Praktikum
*   `dokumen.html` - Praktikum struktur dasar HTML.
*   `heading.html` - Praktikum penggunaan heading.
*   `format.html` - Praktikum format teks.
*   `gambar.html` - Praktikum menyisipkan gambar.
*   `list.html` - Praktikum pembuatan list.
*   `latihan1.html` & `latihan2.html` - Latihan penyusunan layout dokumen sederhana.
*   `tugas.html` - Tugas pembuatan biodata menggunakan HTML dasar.
