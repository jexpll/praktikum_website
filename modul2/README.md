# Modul 2: HTML Lanjut

Modul ini adalah kelanjutan dari Modul 1. Tujuannya adalah untuk memahami elemen-elemen HTML tingkat lanjut yang sering digunakan dalam pembuatan struktur dan antarmuka web.

## Materi Pembahasan
Pada modul ini, fokus materi meliputi:
1.  **Semantic Layout:** Pengenalan tag layout seperti `<header>`, `<main>`, `<section>`, `<nav>`, dan `<footer>` (referensi teori).
2.  **Hyperlink:** Menghubungkan antar halaman atau posisi tertentu di dalam web menggunakan tag `<a>` (Anchor) dan atribut `href`.
3.  **Form:** Membuat formulir interaktif untuk mengumpulkan input dari pengguna menggunakan tag `<form>`, `<input>`, `<textarea>`, dan `<label>`.
4.  **Tabel:** Menyajikan data secara terstruktur menggunakan baris dan kolom dengan tag `<table>`, `<tr>`, `<th>`, dan `<td>`, serta penggunaan `rowspan` dan `colspan`.

## File Praktikum
*   `Hyperlink/` (Folder) - Berisi `halaman1.html` dan `halaman2.html` untuk mempraktikkan navigasi hyperlink.
*   `form.html` - Praktikum pembuatan form dengan berbagai tipe input.
*   `tabel.html` - Praktikum pembuatan tabel dasar dan *span* (row/col).
*   `latihan.html` - Latihan membuat form registrasi/pendaftaran.
*   `percobaan.html` - File percobaan tambahan.
