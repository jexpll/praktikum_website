# Modul 4: Pengenalan JavaScript

## Deskripsi Umum
JavaScript adalah bahasa *scripting* pertama untuk web yang berjalan secara terintegrasi di dalam dokumen HTML. Bahasa ini dirancang untuk memberikan kemampuan tambahan pada HTML dengan cara mengeksekusi perintah secara langsung di sisi pengguna (*client-side* atau browser), bukan di sisi *server*.

## Karakteristik dan Sifat JavaScript
* **Tanpa Compiler Eksternal:** JavaScript bergantung langsung pada browser (yang sudah memiliki *compiler* bawaan) untuk membaca *script* yang terselip di HTML. Berbeda dengan Java, JavaScript tidak butuh penterjemah atau *compiler* khusus.
* **Mudah Dipelajari:** Memiliki struktur yang mudah dipahami karena konsepnya mirip dengan bahasa pemrograman visual, Java, maupun C.
* **Case Sensitive:** JavaScript membedakan penggunaan huruf besar dan huruf kecil dalam penamaan variabel maupun fungsi.
* **Penulisan Sintaks:** Sama seperti C dan Java, setiap instruksi kode dalam JavaScript harus diakhiri dengan karakter titik koma (`;`).

## Fungsi dan Kegunaan Utama
1. **Validasi Formulir:** Digunakan untuk memvalidasi data masukan dari pengguna pada formulir *website* sebelum data tersebut dikirimkan ke *server*.
2. **Interaktivitas:** Mampu mengimplementasikan elemen dinamis seperti permainan interaktif di dalam halaman web.
